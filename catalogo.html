¿Cómo funciona el diseño Responsive aquí?

Este sitio web utiliza CSS Grid y Flexbox, junto con Media Queries, para adaptarse a cualquier pantalla.

  • En Escritorio: El menú está alineado horizontalmente y el catálogo muestra hasta 4 columnas de zapatos.
  • En Tablets: El catálogo se reduce a 2 columnas para que los zapatos se vean grandes y claros.
  • En Celulares: El menú se apila verticalmente y el catálogo muestra 1 sola columna para facilitar el desplazamiento táctil.

Redimensiona la ventana de tu navegador para ver los cambios en tiempo real.
